# 常见问题

## API Key 在哪里填？

启动服务后打开首页，在「DeepSeek Key（可选）」输入框填写。提交后，浏览器调用 `/api/config/key`，密钥只保存在当前服务进程的内存中，不写文件、数据库或日志；重启服务即失效。

也可在服务端设置 `DEEPSEEK_API_KEY`。模型网关的优先级是：网页本次填写的内存密钥、调用参数中的密钥、`DEEPSEEK_API_KEY`。如需兼容网关，可设置 `DEEPSEEK_BASE_URL`。

## 没有 Key 能玩吗？

可以进行非模型部分：选择剧本和岗位、新开对局、点击确认问题/预算/工期、选择路线、提交方案、按规则结算、查看过程评价与复盘。`/api/game/action` 不依赖模型。

NPC 对话和 AI 导演文本不可用。网关找不到密钥时返回 `400` 和「服务端未配置 DeepSeek API 密钥」；前端会在 NPC 对话区显示「对话暂不可用」，而导演事件会保留确定性播报，不影响规则状态、预警和结算。

## 工程数字「待校准」是什么意思？

这表示剧本里的预算、工期、指标初值/目标、路线效果、事件阈值等是教学示意数据，尚待领域专家校准。例如《寒冬订单》的 JSON 在这些字段上明确标有 `calibration: "待校准"`，并列出需要校准的电堆低温衰减、预热/保温成本与工期等项目。

它不表示规则会随机变化，也不表示这些数字可以由 AI 修改：当前值仍由服务端确定性引擎按剧本配置计算。用于真实教学或评估前，应由相应领域专家复核并留存版本依据。

## 如何贡献剧本？

请遵循 [剧本贡献指南](./剧本贡献指南.md)。剧本由 `backend/scripts/` 下的 JSON 配置加载，角色卡位于 `backend/scripts/cards/`；加载器会校验角色卡必填字段、NPC ID 唯一性、导演调度和 World Info 对 NPC 的引用。新增或修改剧本后，应运行 `npm test`。

## 为什么重启后找不到刚才的对局？

目前对局状态存放在 `routes/game.js` 的进程内 `Map`，重启 Node 进程会清空。SQLite 虽会创建默认 `data/demo.db`，但当前仅保存迁移占位表，`saveGameState/loadGameState` 还是预留接口；对局尚未持久化。

## 页面提示「未找到对局」怎么办？

先新开一局，并在后续请求中携带返回的 `gameId`。`/api/game/dialog`、`/api/game/dm` 和教师复核接口要求有效的 `gameId`；`/api/game/action`、`/state`、`/review` 虽有回退逻辑，但多局并存时不应依赖「最近一局」。服务重启后需要重新开局。

## 模型调用失败或超时怎么办？

确认服务端有可用的 API Key，再检查 `DEEPSEEK_BASE_URL` 是否指向兼容服务。模型网关默认 30 秒超时；上游非成功状态、网络异常或超时会统一返回 `502`。查看服务进程的错误与反向代理日志，但不要记录或粘贴 API Key。规则操作仍可继续进行。

## 为什么 NPC 不知道我认为它应该知道的信息？

NPC 不是全知角色。服务端按照剧本每个 NPC 的 `visibleFields` 白名单过滤状态，再把过滤后的结果注入其 prompt；角色卡还包含「知道什么 / 不知道什么」和红线。请通过找对角色、提问命中关键词或执行现场动作来获取信息。

## 为什么提交方案后仍未通过？

结算只检查三项硬约束：预算不超过上限、工期不超过上限、指标达到目标（指标方向由剧本定义）。结算结果来自服务端规则引擎，而不是 AI 对方案文字的主观判断。复盘页的状态曲线和决策时间线可用于定位超限或指标不足的原因。

## `npm install` 或 SQLite 相关依赖安装失败怎么办？

确认使用 Node.js 18+，并使用项目目录中的 `package.json` 执行安装。`better-sqlite3` 是原生依赖，特定操作系统/CPU 上可能需要与 Node 版本匹配的预编译包或本机编译工具链；具体工具链组合取决于部署平台，待确认。不要删除现有 lockfile 或改动依赖来绕过问题，先记录 Node/npm/系统版本和完整错误信息。
